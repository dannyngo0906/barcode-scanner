🎥 Công nghệ mở Camera
1. WebRTC getUserMedia API
navigator.mediaDevices.getUserMedia({
  video: {
    facingMode: { ideal: 'environment' }, // Camera sau (ưu tiên)
    width: { ideal: 1920, min: 640 },     // Độ phân giải cao
    height: { ideal: 1080, min: 480 },    // Tỷ lệ 16:9
    aspectRatio: { ideal: 16/9 },         // Cố định tỷ lệ
    frameRate: { ideal: 30, min: 15 }     // 30 FPS tối ưu
  },
  audio: false // Không cần audio
})
2. Camera Constraints
facingMode: environment (camera sau) vs user (camera trước)
Resolution: 1920x1080 (Full HD) với fallback 640x480
Frame Rate: 30 FPS lý tưởng, tối thiểu 15 FPS
Aspect Ratio: 16:9 để tối ưu cho barcode scanning
📱 Công nghệ quét Barcode (3 tầng)
Tầng 1: QuaggaJS (Primary)
Thư viện chuyên nghiệp cho barcode detection

Cấu hình QuaggaJS:

{
  frequency: 5,                    // Quét mỗi 200ms
  numOfWorkers: 4,                 // 4 worker threads song song
  halfSample: false,               // Dùng full resolution
  
  inputStream: {
    area: {                        // Vùng quét focus
      top: "20%", bottom: "20%",
      left: "10%", right: "10%"
    },
    singleChannel: false           // RGB color (chính xác hơn)
  },
  
  decoder: {
    readers: [                     // 9 định dạng barcode
      "code_128_reader",           // Code 128
      "ean_reader",                // EAN-13  
      "ean_8_reader",              // EAN-8
      "code_39_reader",            // Code 39
      "code_39_vin_reader",        // Code 39 VIN
      "codabar_reader",            // Codabar
      "upc_reader",                // UPC-A
      "upc_e_reader",              // UPC-E
      "i2of5_reader"               // Interleaved 2 of 5
    ],
    multiple: false                // Chỉ detect 1 barcode/lần
  }
}
Tầng 2: BarcodeDetector API (Fallback)
API native của browser (Chrome, Edge)

new BarcodeDetector({
  formats: [
    'code_128', 'code_39', 'ean_13', 
    'ean_8', 'upc_a', 'upc_e', 'qr_code'
  ]
})
Tầng 3: Enhanced Pattern Detection (Final Fallback)
Thuật toán custom cho các browser không hỗ trợ:

Contrast Analysis: Phân tích độ tương phản
Pattern Recognition: Nhận diện pattern đen-trắng
Center Sampling: Lấy mẫu vùng trung tâm
Grid Sampling: Quét theo lưới 5x5 pixel
⚙️ Thông số Performance
Timing & Debouncing
// Tần suất quét
QuaggaJS: 200ms intervals (5 FPS)
Fallback: 100ms intervals (10 FPS)
// Debouncing (tránh detect trùng)
QuaggaJS: 1200ms minimum gap
BarcodeDetector: 1200ms minimum gap  
Pattern Detection: 1500ms minimum gap
// Pause sau detection
Thành công: 2000ms - 2500ms pause
Camera Initialization
// States
'idle' → 'loading' → 'ready' → 'scanning'
// Timing
Camera stabilization: 500ms delay
Error timeout: Immediate
Stream cleanup: Complete track stop
UI/UX Optimization
// Visual feedback
Loading spinner: 16x16 với border animation
Ready indicator: Green pulsing dot
Scanning overlay: Animated scan line 1.2s
Success flash: 300ms green overlay
// Error handling
Permission denied → Permission modal
Camera error → Error state display
Fallback chain → Automatic switching
🔧 Image Processing
Canvas Operations
// Real-time frame capture
canvas.width = video.videoWidth
canvas.height = video.videoHeight
context.drawImage(video, 0, 0, width, height)
// Image analysis
getImageData() → pixel analysis
Brightness calculation: (R+G+B)/3
Contrast ratio: |dark-light|/total
Detection Algorithm
// Enhanced pattern detection
Sample radius: min(width, height)/4
Grid sampling: Every 5 pixels
Contrast threshold: > 25%
Distribution check: 20% dark + 20% light minimum
Success probability: 15% per frame
